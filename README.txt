BOT DE VENDAS - FACÇÃO

Arquivos:
- index.js
- package.json
- banco.sql
- .env.example

Comando:
 /venda

O comando registra item, quantidade, valor e cliente, salva no MySQL e envia um embed para o canal definido em CANAL_VENDAS.

No Render, configure as variáveis de ambiente usando o conteúdo de .env.example.
